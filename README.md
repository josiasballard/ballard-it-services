# Ballard IT Services

Official website for **Ballard IT Services**, a small-business IT support provider based in Dover, Delaware.

Ballard IT Services provides practical, remote-first technology support for small businesses that need dependable IT help without maintaining a dedicated internal IT department.

## Services

- Windows and business computer support
- Remote troubleshooting and technical support
- Local onsite IT support
- Microsoft 365 administration and support
- Outlook, Teams, and OneDrive support
- User account and access administration
- MFA and sign-in troubleshooting
- Employee onboarding and offboarding
- PC setup, deployment, and migration
- Hardware troubleshooting and replacement
- IT inventory and documentation
- Ongoing IT support for small businesses

## Service Area

Based in **Dover, Delaware**, serving small businesses throughout Dover and surrounding Central Delaware.

Support is remote-first, with local onsite assistance available when hands-on service is needed.
